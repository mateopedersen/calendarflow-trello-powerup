# CalendarFlow Quick Guide

1. Enable CalendarFlow on a Trello board.
2. Click **Printable Calendar** in the board toolbar.
3. Switch among Month, Week, Year, Insights, and Resources.
4. Select Monday or Sunday as the first weekday. Use the arrows and Today control to navigate.
5. Set paper, page orientation, card-title visibility, and monochrome printing under **Print settings**.
6. Choose **Print / Save PDF** to use your browser's print dialog. CalendarFlow does not create a PDF service-side.
7. Use CSV or ICS to download the current board's deadlines to this device. ICS events use the card due time; date-only values export as all-day events.

### Calendar behavior

Dates with a start or due date appear in day cells. Clicking a date shows its related cards. Card names link to their Trello cards when Trello provides a URL. Analytics count cards, not hours or effort: overdue means an incomplete due date falls before today's local calendar date; upcoming means an incomplete due date is today or later.

### Resources

The Resources panel contains optional Beta Calendars links. These open only after you click them. No Trello card information is added to a resource link.
