# CalendarFlow Support

CalendarFlow is a read-only Trello Power-Up by Beta Calendars.

## Getting help

For questions about setup or a problem with the planner, use the [Beta Calendars contact page](https://www.betacalendars.com/contact) and include “CalendarFlow” in the message. Do not include private board names, card content, or access tokens in a support request.

## Quick troubleshooting

- Enable CalendarFlow on the board, then choose **Printable Calendar** in the board toolbar.
- If the planner cannot read cards, close and reopen it from the board. Archived cards and cards in archived lists are not included by Trello's visible-card API.
- If local preferences appear stale, clear site data for the hosted connector and set the week start again.
- CSV and ICS are downloaded by your browser. Check the browser's download shelf if a file does not appear.
- For a PDF, choose **Print / Save PDF** and select the browser's Save as PDF destination.

## Data and permissions

See the [Privacy Notice](./privacy.html). CalendarFlow does not modify Trello cards or send board contents to Beta Calendars.
